# BookPickAI 작업 기록 — 2026-07-29

## 1. 오늘 작업 요약

BookPickAI의 백엔드와 실제 데이터 연동을 시작하기 전에 전체 서비스 흐름을 확인할 수 있도록 프론트엔드 UI 프로토타입을 확장했다.

오늘 작업한 주요 범위는 다음과 같다.

- 메인 페이지와 AI 추천 페이지 분리
- 메인 개인 맞춤 추천 영역 추가
- 장르별 도서 탐색 및 검색 필터 연결
- 인기 도서 가로 스와이프 캐러셀 구현
- 더미 도서 데이터 6권에서 12권으로 확장
- 로그인 및 회원가입 화면 구현
- 사용자 프로필과 취향 설정 화면 구현
- 내 서재와 최근 본 책 화면 보강
- 관리자 대시보드 구현
- 데이터 수집 및 AI 분석 작업 상세 패널 구현
- 상단 로그인·프로필·로그아웃 흐름 연결
- 반응형 레이아웃과 줄바꿈 문제 수정

현재 화면에 표시되는 도서, 리뷰 분석 결과, 사용자 통계와 관리자 작업 현황은 모두 Mock 데이터다.

- React 19

## 4. 로그인 데모

현재 인증은 서버 인증이 아니라 브라우저 `localStorage`를 사용하는 Mock 인증이다.

### 일반 사용자

```text
이메일: reader@bookpick.ai
비밀번호: bookpick1234
```

로그인 후 `/profile`로 이동한다.

### 관리자

```text
이메일: admin@bookpick.ai
비밀번호: bookpick1234
```

로그인 화면에서 `관리자 데모`를 선택한 후 로그인하면 `/admin`으로 이동한다.

실제 Spring Boot 인증을 연결할 때는 `frontend/src/store/AuthContext.tsx`의 Mock 로그인 처리를 API 호출과 토큰 처리로 교체한다.

## 5. 메인 및 추천 화면

### 메인 페이지

- 검색창
- AI Pick 대표 도서
- 오늘의 개인 추천 3권
- 인기 도서 12권 캐러셀
- 장르별 탐색
- 리뷰 감정 분석 소개
- AI 추천 챗봇 진입 버튼

인기 도서는 다음 방법으로 이동할 수 있다.

- 모바일 터치 스와이프
- 트랙패드 가로 스크롤
- PC 이전·다음 버튼

### AI 추천 페이지

- 원하는 분위기 선택
- 선호 장르 선택
- 독서 시간 선택
- 현재 취향 요약
- `취향에 가까운 추천`과 `새로운 발견` 선택
- 추천 이유와 취향 일치율
- 추천별 좋아요·아쉬워요 피드백

현재 추천 결과는 `mockBooks`를 조건에 따라 정렬하는 데모 로직이다.

## 6. 마이페이지 및 내 서재

마이페이지에는 다음 내용이 있다.

- 표시 이름 수정
- 선호 장르 설정
- 평소 독서 시간 설정
- 취향 저장
- 찜한 책·최근 본 책·추천 피드백 통계
- 최근 독서 활동
- 최근 본 책

상단 통계 카드와 취향 태그는 현재 표시용이다. 추후 다음 흐름으로 연결하는 것이 좋다.

- 찜한 책 → 내 서재 찜 목록
- 최근 본 책 → 최근 조회 목록
- 추천 피드백 → 추천 평가 기록
- 취향 태그 → 취향 설정 영역 또는 태그 수정 화면

## 7. 관리자 페이지

관리자 대시보드에는 다음 운영 정보를 표시한다.

- 수집 도서 수
- 확보 리뷰 수
- 가입 사용자 수
- 처리 오류 수
- FastAPI 분석 서버 상태
- 감정 분석·키워드 추출·리뷰 요약 처리율

### 데이터 파이프라인

현재 화면이 표현하는 처리 흐름은 다음과 같다.

```text
도서 정보 수집
    ↓
리뷰 수집
    ↓
텍스트 전처리
    ↓
BERT 감정 분석
    ↓
키워드 추출 및 리뷰 요약
    ↓
PostgreSQL 저장
    ↓
추천 및 도서 상세 화면 반영
```

### 작업 상세 패널

관리자 테이블의 `상세` 버튼을 누르면 우측 패널이 열린다.

- 실행 ID
- 진행률
- 성공·실패·제외 건수
- 데이터 소스와 처리 대상
- 시작 시간과 최근 갱신
- 작업 단계
- 최근 실행 로그
- 로그 복사
- 다시 실행
- 작업 중단
- 지금 실행
- 실패 항목 재시도
- 데이터 연결 메모 확인

현재 관리 버튼들은 안내 메시지만 표시하는 Mock 동작이다.

추후 연결할 API 예시는 다음과 같다.

```text
GET  /api/admin/jobs
GET  /api/admin/jobs/{jobId}
POST /api/admin/jobs/{jobId}/run
POST /api/admin/jobs/{jobId}/cancel
POST /api/admin/jobs/{jobId}/retry
GET  /api/admin/jobs/{jobId}/logs
```

## 8. 데이터 및 API 진행 상황

### 알라딘

- Open API 키 발급 완료
- 키는 `crawler/.env`에 저장
- `.env` 파일은 Git에 올라가지 않음
- 집 컴퓨터에서는 별도로 환경 변수를 다시 만들어야 함

주의: API 키를 Markdown, 코드 또는 Git 커밋에 직접 작성하지 않는다.

### YES24

- 데이터 활용 및 리뷰 사용 가능 여부 문의 완료
- 현재 담당자 답변 대기 중
- 답변 전까지 관리자 화면에서는 `연결 대기` 상태로 표현

리뷰 수집 범위와 저장·가공·공개 가능 여부는 YES24의 답변을 확인한 후 결정한다.

## 9. 집에서 이어서 실행하는 방법

### 저장소 받기

새로 복제할 경우:

```bash
git clone https://github.com/carrotkang/BookPickAI.git
cd BookPickAI
```

이미 저장소가 있을 경우:

```bash
git switch main
git pull origin main
```

### 패키지 설치

프로젝트 루트에서:

```bash
npm --prefix frontend install
```

또는 프론트엔드 폴더에서 직접 설치할 수 있다.

```bash
cd frontend
npm install
```

### 개발 서버 실행

프로젝트 루트에서:

```bash
npm run dev
```

기본 접속 주소:

```text
http://localhost:5173
```

### 검증 명령

```bash
npm run build
npm run lint
```

## 11. 다음 작업 후보

API 및 데이터 활용 답변을 기다리는 동안 다음 순서로 진행할 수 있다.

1. 마이페이지 상단 통계 카드 클릭 동작 구현
2. 찜·최근 조회·추천 피드백 전역 상태 정리
3. Spring Boot 프로젝트 초기 설정
4. PostgreSQL ERD와 엔티티 확정
5. 회원가입·로그인 API 및 Spring Security 구현
6. 알라딘 Open API 도서 수집기 구현
7. Spring Boot와 FastAPI 사이의 분석 요청 명세 작성
8. FastAPI 감정 분석 Mock API 구현
9. 관리자 작업 API와 프론트 상세 패널 연결
10. 배포용 Docker Compose 구성

데이터 제공 범위가 확정되기 전에는 리뷰 크롤러를 본격적으로 구현하지 않고, 도서 메타데이터 수집과 API 구조부터 만드는 편이 안전하다.
